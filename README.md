# CMU AI Agents Learning Wiki

An Obsidian vault and Git repository for building a persistent, LLM-maintained
knowledge base over time.

## Open the vault

1. Open Obsidian.
2. Choose **Open folder as vault**.
3. Select this repository.

Start at [[Home]]. Drop quick thoughts and unprocessed material into `inbox/`.
Put original source files in `raw/`; those files are treated as immutable. Ask
Codex to ingest a source when you want it integrated into `wiki/`.

The course itself has intentionally not been imported or pre-structured. The
vault will grow only from material you choose to add.

## Repository layout

- `inbox/` — frictionless capture awaiting review
- `raw/` — original source material; never edited during ingestion
- `raw/assets/` — local images and attachments
- `wiki/` — maintained summaries, concepts, comparisons, and synthesis
- `templates/` — optional note templates
- `AGENTS.md` — operating rules for the LLM maintainer
