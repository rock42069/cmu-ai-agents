# ReAct: Synergizing Reasoning and Acting in Language Models

Shunyu Yao, Jeffrey Zhao, Dian Yu, Nan Du, Izhak Shafran, Karthik Narasimhan,
and Yuan Cao (ICLR 2023).

## Brief

ReAct is a prompting paradigm in which a language model alternates between
free-form **thoughts**, task-specific **actions**, and environment-provided
**observations**. Reasoning helps form and revise plans; actions retrieve facts
or change the environment; observations ground the next reasoning step. Across
question answering, fact verification, a text-based household environment, and
a simulated shopping site, the paper shows why reasoning-only and acting-only
approaches have complementary weaknesses—and why an effective agent loop needs
both.

## Summary

### The basic loop

A conventional action policy maps the interaction history directly to its next
environment action. ReAct expands the action space with language-only thought
steps. Thoughts do not affect the external environment, but they update the
context used for later thoughts and actions. They can decompose a goal, record
progress, extract relevant facts from an observation, introduce commonsense,
recognize an exception, reformulate a search, or decide that the task is done.

For knowledge-intensive tasks, the demonstrated trajectories densely alternate
`Thought -> Action -> Observation`. For long-horizon decision tasks, reasoning
is sparse and appears mainly around planning, subgoal transitions, and
exceptions. The paper primarily prompts a frozen PaLM-540B with a handful of
human-written trajectories; it also studies fine-tuning smaller models on 3,000
successful trajectories generated by ReAct.

### Knowledge-intensive reasoning

HotpotQA and FEVER are evaluated without their supporting passages. The agent
can use a deliberately simple Wikipedia interface with `search`, `lookup`, and
`finish` actions. This makes the retrieval path explicit and allows observations
to correct or extend the model's internal knowledge.

ReAct consistently beats acting alone, showing that retrieval is not enough:
the model must decide what to search for, relate observations, and synthesize an
answer. Relative to chain-of-thought (CoT), ReAct is more grounded but not always
more accurate. It beats CoT on FEVER (60.9 versus 56.3 accuracy) but slightly
trails it on HotpotQA (27.4 versus 29.4 exact match). A manual analysis finds no
hallucination among the sampled ReAct failures versus 56% of sampled CoT
failures, but ReAct has more reasoning errors and can loop or be derailed by an
uninformative search result.

The strongest prompting results combine ReAct with self-consistent CoT. One
method falls back to CoT when ReAct exceeds a step limit; the other invokes
ReAct when sampled CoT answers lack a majority. This matters conceptually:
internal parametric knowledge and external retrieval are complements, and a
system can route between them based on failure or uncertainty.

Fine-tuning changes the scaling story. Although smaller PaLM models struggle to
learn the combined format from a few demonstrations, fine-tuning on successful
ReAct trajectories makes ReAct the strongest of the compared formats. This is
initial evidence, not a complete training recipe: the generated dataset is
filtered by answer correctness and remains small.

### Interactive decision-making

In ALFWorld, the model navigates a text household and performs long sequences of
actions. Sparse thoughts help it use commonsense to prioritize likely locations,
decompose goals, and track completed subgoals. The best ReAct prompt reaches 71%
success, versus 45% for action-only prompting and 37% for the imitation-learning
BUTLER baseline. Performance varies across prompt permutations, so the paper
reports both averages and best trials.

In WebShop, the agent searches and navigates a simulated store built from real
product text. ReAct improves success from 30.1% for action-only prompting to
40.0%, outperforming the reported imitation and imitation-plus-RL baselines,
but remaining well below the 59.6% human expert result. Reasoning helps map noisy
product descriptions and options back to user constraints.

An ablation patterned after dense external-feedback “inner monologue” performs
worse than flexible, sparse ReAct reasoning in ALFWorld. Merely restating state
and remaining goals is not equivalent to reasoning about subgoal completion,
next actions, likely object locations, or exceptions.

### Interpretability and control

Because thoughts, actions, and observations are visible, an observer can often
locate whether a failure came from reasoning, retrieval, or action. The paper
also demonstrates that editing two thought steps can redirect a failed ALFWorld
trajectory. This is a promising example of intervention, not proof that visible
reasoning is faithful to all internal computation or that the system is safe.

## Key ideas to keep in mind

- Agent reasoning is most useful when it is **coupled to feedback**: act to get
  information, then revise the plan using what actually happened.
- A tool result is an observation, not an answer. The agent still needs to judge
  relevance, combine evidence, and decide the next action.
- Reasoning cadence should match the environment: dense for multi-hop retrieval,
  sparse around key decisions in long action sequences.
- Grounding trades some flexibility for factuality. Retrieval can reduce
  hallucination while introducing search failures, bad observations, and loops.
- Parametric knowledge and external tools are complementary; routing or fallback
  mechanisms can outperform treating either as universally best.
- Explicit trajectories improve diagnosability, but readable thoughts should
  not automatically be equated with faithful explanations or guarantees.

## Questions and caveats

- Most main prompting experiments use the proprietary PaLM-540B model. The
  authors include limited GPT-3 results and prompts, but exact reproduction is
  constrained.
- The method depends on manually designed action spaces and a small set of
  hand-written demonstration trajectories; results can vary with prompt choice.
- ReAct can repeat earlier steps, reason incorrectly, or fail to recover after
  weak search results. External grounding moves rather than eliminates failure.
- HotpotQA and FEVER scores remain far below supervised task-specific systems.
- The benchmark action spaces are bounded and comparatively safe. Real tools
  can expose private data or perform harmful, irreversible actions; the paper's
  ethics statement explicitly warns about this expansion.
- Visible thoughts aid debugging and intervention, but the paper does not test
  whether the verbal trace is a causally faithful account of model computation.
